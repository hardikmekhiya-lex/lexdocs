# LexDocs

વકીલની ઓફિસ માટે દસ્તાવેજ બનાવવાનું સોફ્ટવેર (Windows). આ repository માં ફક્ત ઇન્સ્ટોલર છે — “Releases” માં.

## ઇન્સ્ટોલ કેવી રીતે કરવું
1. Releases માંથી `LexDocs-…-Setup.exe` ડાઉનલોડ કરો.
2. તેના પર બે વાર ક્લિક કરો. વાદળી “Windows protected your PC” આવે તો: **More info → Run anyway**.
3. Next → Install.
4. પહેલી વાર ખૂલે ત્યારે ઓફિસનું નામ અને LexDocs આપનારે આપેલી **key** લખો.

## નવું વર્ઝન
નવું ઇન્સ્ટોલર જૂના LexDocs ઉપર જ ઇન્સ્ટોલ કરો — તમારો ડેટા, key અને ટેમ્પ્લેટ એમ જ રહે છે.
